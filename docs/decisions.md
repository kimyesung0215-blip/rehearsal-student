# decisions.md

## 2026-09-15 — 초기 설계 결정
1. **역할 재정의**: 이 앱은 교사 훈련 도구가 아니라 "학습자(예성)의 이해 검출 파이프라인" 일부.
   앱 책임 = 청중 실재감 + 녹음/러프 전사. 평가 책임 = 앱 밖 (Claude 페르소나).
2. **2층 반응 구조 채택**: 1층 VAD(오프라인 보장) + 2층 키워드 큐(온라인, 실패 시 강등).
   AI 실시간 호출은 지연·비용·불안정성 때문에 배제.
3. **STT 역할 축소**: Web Speech API를 공식 전사 담당에서 해고, 반응 트리거로만 사용.
   정밀 전사는 녹음 파일 → 클로바노트 외부 처리.
4. **배포처 GitHub Pages**: 정적 앱 + HTTPS 필수(getUserMedia) 충족. base: './' 상대경로.
5. **아바타**: 플랫 덩어리 스타일 오리지널 캐릭터(SVG + CSS 애니메이션). 외부 에셋/라이브러리 없음.
6. **튜닝 상수 분리**: VAD 임계값·정적 대기시간·패턴은 실기기 테스트 전 확정 불가 → tuning.js로 격리.
7. **세션 히스토리 추가**: 사용자 요청으로 세션 녹음과 러프 전사를 IndexedDB에 로컬 저장.
   서버 전송 없이 현재 기기·브라우저에서만 조회·재생·다운로드·삭제한다.
